# Customer Support Chatbot with RAG 
 
This project implements a support chatbot using LangChain, Gemini API, Google Search API and FAISS as a vector database. Implemented on GCP with Github CI/CD.

Demo: https://custom-ai-chatbot-frontend-54452819884.us-central1.run.app/
